# Instalando ambiente virtual

Olhando a versão do Python
```Console 
python --version
```
Criando o ambiente virtual
```Console 
python -m venv .venv
```

Ativando o ambiente.

No Powershell
```Console 
.\.venv\Scripts\Activate.ps1
```

Quando funcionar o prompt deve estar assim:
```Console 
(.venv) PS :\Meu Drive\Cursos\Python\DataCleaningInPythonEssentialTraining>
```
